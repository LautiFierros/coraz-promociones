¿Cómo funciona esta app?

Gestiona las promociones de Mercado Libre de CORAZ sin entrar publicación por publicación.

De dónde salen los datos

Se consulta en vivo la API de Mercado Libre (recurso seller-promotions) usando el mismo token que ya usan el resto de las apps de CORAZ. No hay copia local de las promociones — lo que ves es el estado real en ML en el momento de cargar la página.

Los 12 tipos de promoción

Cada card muestra un tipo. Los que tienen borde ámbar y botones ("Campaña propia" y "Campaña tradicional") los controlás vos por completo: podés subir todas las publicaciones candidatas de una campaña con un clic, o bajarlas todas. El resto son invitaciones de ML — se muestran para que sepas qué tenés corriendo, pero todavía no se pueden gestionar en bloque desde acá (algunos ML los aplica automáticamente, como "Co-participación automática").

Subir a todas / Bajar de todas

"Subir a todas" busca las publicaciones candidatas de esa campaña puntual y les aplica el precio calculado con el % que configuraste para cada SKU (o el default si no tiene uno propio). "Bajar de todas" saca las que están activas. Ambas acciones te muestran un detalle publicación por publicación al terminar.

% de descuento por SKU

Es la configuración que usa "Subir a todas" para calcular el precio de cada publicación. Se guarda en la base de CORAZ, no en Mercado Libre, así que podés ajustarla cuando quieras sin afectar nada hasta que vuelvas a apretar "Subir a todas".
